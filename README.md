# Monte Carlo Portfolio Risk Simulator

## Overview
A Python-based project that uses Monte Carlo simulation to analyze portfolio performance and estimate potential investment risks under different market conditions.

## Features
- Simulates multiple portfolio outcomes.
- Models returns for different asset classes.
- Calculates portfolio value across simulated scenarios.
- Estimates Value at Risk (VaR).
- Visualizes portfolio outcome distributions using Matplotlib.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Google Colab

## Methodology
1. Define the initial portfolio and asset allocation.
2. Generate random asset returns using probability distributions.
3. Simulate portfolio performance over a specified investment period.
4. Analyze the distribution of final portfolio values.
5. Estimate potential downside risk using Value at Risk.

## Future Improvements
- Add asset correlation modeling.
- Implement Conditional Value at Risk (CVaR).
- Compare different portfolio allocations.
- Incorporate historical market data.

## Disclaimer
This project is intended for educational purposes only. Simulation results depend on the assumptions used and should not be considered financial advice.
